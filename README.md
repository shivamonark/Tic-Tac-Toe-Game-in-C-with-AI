# Tic-Tac-Toe Game in C with AI 

A console-based Tic-Tac-Toe game developed in C, where the player competes against an unbeatable AI implemented using the Minimax algorithm.

---

## 🎮 Features

- Player vs Computer gameplay
- Unbeatable AI using Minimax
- Robust input validation to handle invalid input
- Clean and simple console-based interface

---

## 🧠 AI Logic

The computer player uses the **Minimax algorithm**, which evaluates all possible future game states and selects the optimal move.  
This guarantees that the AI **never loses**.

---

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Git & GitHub

---

## ▶️ How to Compile and Run

```bash
gcc tic_tac_toe.c -o tic_tac_toe
./tic_tac_toe
```

---

## 🕹️ How to Play

- Enter your move as two numbers: **row column** (both from 0 to 2)
- Example:
```
Your move (row col): 1 1
```
- The game ends when either the player or the AI wins, or when the match is a draw.
